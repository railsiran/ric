# نصب سریع

`ric` یک باینری مستقل و تک‌فایلی است که با زبان Go نوشته شده است. نه نصاب می‌خواهد، نه پکیج باید ثبت کنید، نه وابستگی‌ای را باید کامپایل کنید.

## پیش‌نیازها

روی دستگاهی که می‌خواهید `ric` را اجرا کنید، به سه چیز نیاز دارید:

۱. **داکر** — تمام کارهای `ric` داخل کانتینرهای داکر انجام می‌شود. روی مک یا ویندوز Docker Desktop را نصب کنید، و روی لینوکس `docker` و `docker compose` را. با اجرای `docker --version` نصب را تایید کنید.

۲. **یک کلاینت SSH** — فقط در صورتی لازم است که قصد استفاده از `ric deploy` و `ric upgrade` را داشته باشید. مک، لینوکس و نسخه‌های جدید ویندوز همگی کلاینت SSH دارند.

۳. **دسترسی به اینترنت** — اولین بار که `ric new` را اجرا می‌کنید، یک ایمیج داکر از رجیستری ایمیج railsiran دانلود می‌شود. در اجراهای بعدی از نسخه‌ی محلی استفاده می‌شود.

نیازی **ندارید** که Ruby روی سیستم میزبان نصب باشد، نیازی **ندارید** که bundler داشته باشید، و نیازی **ندارید** که هیچ gem ای از Rails نصب کنید. همه چیز مربوط به Ruby داخل کانتینر زندگی می‌کند.

## دریافت باینری

از آخرین نسخه‌ی منتشرشده در سایت railsiran، فایل مناسب پلتفرم خودتان را دانلود کنید. نام‌ها نشان می‌دهند کدام را بگیرید:

| پلتفرم | فایل |
|----------|------|
| مک (Apple Silicon) | `ric-darwin-arm64` |
| لینوکس x86_64 | `ric-linux-amd64` |
| لینوکس ARM (رزبری پای، AWS Graviton و …) | `ric-linux-arm64` |
| ویندوز | `ric-windows-amd64.exe` |

## قابل اجرا کردن و قرار دادن در PATH

روی مک یا لینوکس:

```bash
chmod +x ~/Downloads/ric-darwin-arm64
sudo mv ~/Downloads/ric-darwin-arm64 /usr/local/bin/ric
```

روی ویندوز، فایل `ric-windows-amd64.exe` را در پوشه‌ای قرار دهید که در `PATH` شما باشد (یا از طریق System Properties → Environment Variables آن پوشه را به PATH اضافه کنید).

## اعتبارسنجی

```bash
ric version
```

باید شماره‌ی نسخه و codename بیلد را ببینید. اگر پیام «command not found» گرفتید، باینری هنوز در PATH شما نیست.

## مرحله‌ی بعد

- تازه با ric آشنا شدید؟ `ric new myapp` را اجرا کنید — [`ric new`](02-new.md).

# نصب سریع

`ric` یک باینری مستقل و تک‌فایلی است که با زبان Go نوشته شده است. نه نصاب می‌خواهد، نه پکیجی باید ثبت کنید، نه وابستگی‌ای را باید کامپایل کنید.

## پیش‌نیازها

روی دستگاهی که می‌خواهید `ric` را اجرا کنید، به سه چیز نیاز دارید.

اولین مورد **داکر** است. تمام کارهای `ric` داخل کانتینرهای داکر انجام می‌شود. روی مک یا ویندوز Docker Desktop را نصب کنید، و روی لینوکس `docker` به همراه `docker compose` را. نصب را با این دستور تایید کنید:

```bash
docker --version
```

دومین مورد **یک کلاینت SSH** است، اما فقط در صورتی که قصد استفاده از `ric deploy` و `ric upgrade` را داشته باشید. مک، لینوکس و نسخه‌های جدید ویندوز همگی کلاینت SSH دارند و نیاز به نصب جداگانه نیست.

سومین مورد **دسترسی به اینترنت** برای اولین استفاده است. اولین بار که `ric new` را اجرا می‌کنید، یک ایمیج داکر از رجیستری ایمیج railsiran دانلود می‌شود. در اجراهای بعدی از نسخه‌ی محلی استفاده می‌شود و آفلاین کار می‌کند.

نیازی **ندارید** که Ruby روی سیستم میزبان نصب باشد، نیازی **ندارید** که bundler داشته باشید، و نیازی **ندارید** که هیچ gem ای از Rails نصب کنید. همه چیز مربوط به Ruby داخل کانتینر زندگی می‌کند.

## دریافت باینری

از آخرین نسخه‌ی منتشرشده در سایت railsiran، فایل مناسب پلتفرم خودتان را دانلود کنید. چهار بیلد در دسترس است، یکی برای هر پلتفرم رایج.

روی **مک با چیپ Apple Silicon** (مدل‌های M1، M2، M3، M4)، فایلی که نیاز دارید `ric-darwin-arm64` نام دارد.

روی **لینوکس x86_64** — اکثر کامپیوترهای دسکتاپ، اکثر سرویس‌های VPS، اکثر ماشین‌های مجازی ابری — فایل به نام `ric-linux-amd64` است.

روی **لینوکس ARM** — Raspberry Pi، AWS Graviton، Oracle Ampere و سرورهای ARM مشابه — فایل به نام `ric-linux-arm64` است.

روی **ویندوز** فایل به نام `ric-windows-amd64.exe` است.

## قابل اجرا کردن و قرار دادن در PATH

روی مک یا لینوکس، فایل را قابل اجرا کنید و آن را به پوشه‌ای منتقل کنید که از قبل در PATH شما باشد. انتخاب استاندارد `/usr/local/bin` است. برای مثال، اگر بیلد مک Apple Silicon را دانلود کرده‌اید:

```bash
chmod +x ~/Downloads/ric-darwin-arm64
sudo mv ~/Downloads/ric-darwin-arm64 /usr/local/bin/ric
```

بعد از این جابجایی، فایل به سادگی `ric` نامیده می‌شود، بدون پسوند پلتفرم.

روی ویندوز، فایل `ric-windows-amd64.exe` را در پوشه‌ای قرار دهید که از قبل در `PATH` شما باشد. اگر چنین پوشه‌ای ندارید، چیزی مثل `C:\Tools\` بسازید و آن را از طریق System Properties → Environment Variables → Path اضافه کنید. ممکن است بخواهید فایل را به `ric.exe` تغییر نام دهید تا برای راحتی بتوانید `ric` را به جای `ric-windows-amd64` اجرا کنید.

## اعتبارسنجی

```bash
ric version
```

باید شماره‌ی نسخه و codename بیلد را ببینید. اگر پیام «command not found» گرفتید، باینری هنوز در PATH شما نیست.

## مرحله‌ی بعد

اگر تازه با ric آشنا شده‌اید، `ric new myapp` را اجرا کنید — [`ric new`](02-new.md) را ببینید.

اگر آماده‌ی deploy کردن یک پروژه‌ی موجود هستید، [`ric deploy`](06-deploy.md) را ببینید.

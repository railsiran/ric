# `ric new` — ساخت پروژه‌ی جدید

`ric new <name>` یک پروژه‌ی Rails کاملا جدید را داخل یک کانتینر داکر می‌سازد و سپس فایل‌های پروژه را به دایرکتوری فعلی شما کپی می‌کند تا بتوانید با ادیتور دلخواهتان آن‌ها را ویرایش کنید.

## نحوه‌ی استفاده

```bash
ric new myapp
ric new myapp --css tailwind
ric new myapp --js three
ric new myapp --js p5 --local
```

آرگومان `<name>` هم نام پروژه و هم نام پوشه‌ای است که در دایرکتوری فعلی ساخته خواهد شد. از حروف کوچک انگلیسی، اعداد، خط تیره، آندرلاین و نقطه استفاده کنید.

## کاری که انجام می‌دهد (به ترتیب)

۱. ایمیج پایه را انتخاب می‌کند (جدول flagها را پایین‌تر ببینید).
۲. آن ایمیج را از رجیستری railsiran دانلود می‌کند (یا اگر `--local` داده باشید، روی سیستم محلی پیدا می‌کند).
۳. یک کانتینر داکر به نام `<name>` از روی آن ایمیج اجرا می‌کند.
۴. workspace داخل کانتینر را به `<name>` تغییر نام می‌دهد.
۵. پروژه را از کانتینر به مسیر `./<name>/` روی سیستم شما کپی می‌کند.
۶. یک `config/master.key` جدید می‌سازد و `config/credentials.yml.enc` را با آن دوباره رمزگذاری می‌کند تا پروژه‌ی شما credentialهای منحصربه‌فرد خودش را داشته باشد.

وقتی تمام شد، شما یک کانتینر در حال اجرا، یک پوشه‌ی پروژه روی دیسک، و یک پورت روی میزبان دارید (پیش‌فرض `3000`، در صورت اشغال بودن، خودکار یک پورت بالاتر).

## Flagها

| Flag | ایمیج دانلودشده | شامل |
|------|--------------|----------|
| *(بدون flag)* | `ri_base` | Rails 8 + SQLite + Solid Trifecta |
| `--css tailwind` | `ri_tailwind` | پایه + tailwindcss-rails |
| `--js three` | `ri_three` | tailwind + three.js پین‌شده در importmap |
| `--js p5` | `ri_p5` | tailwind + p5.js |
| `--js react` | `ri_react` | tailwind + react از طریق importmap |
| `--local` | (هر کدام از موارد بالا) | دانلود را رد می‌کند و از ایمیج موجود روی میزبان استفاده می‌کند |

استفاده‌ی همزمان از `--css tailwind` و `--js …` مجاز نیست: هر variant از `--js` خودش از قبل شامل tailwind است، پس ترکیب آن‌ها زائد است و ric با یک پیام راهنما رد می‌کند.

`--local` زمانی مفید است که خودتان ایمیج‌های ric را به صورت محلی می‌سازید (مستندات variantهای ایمیج را ببینید) و می‌خواهید آن‌ها را بدون آپلود در رجیستری امتحان کنید.

## نکات رایج

- **پوشه نباید از قبل وجود داشته باشد.** اگر `./<name>/` وجود داشته باشد، ric از بازنویسی خودداری می‌کند.
- **اعتبارسنجی نام.** نام‌هایی که با عدد شروع می‌شوند رد می‌شوند (Ruby/Rails آن‌ها را به عنوان نام ماژول قبول نمی‌کند).
- **تداخل پورت.** ric از `3000` شروع به جستجو می‌کند و اولین پورت آزاد را برمی‌دارد. اگر پورت 3000 را نمی‌بینید، یعنی چیز دیگری روی سیستم شما به آن گوش می‌داده است.
